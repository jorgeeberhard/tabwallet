# Logos

- `tabwallet-logo.svg` — Assinatura principal, para fundos claros (`bg-canvas`, `bg-surface`). Índigo `#4b3fd6`, Lavanda `#8b83f0` e Grafite `#161a23`.
- `tabwallet-logo-negative.svg` — Para fundos escuros (`bg-canvas` do tema escuro). Lavanda, `#c9c4fa` e Névoa; o fecho é recortado em `#161a23`.
- `tabwallet-logo-white.svg` — Monocromático branco, só sobre `brand-primary` claro (`#4b3fd6`); o fecho é Índigo.
- `tabwallet-logo-mono.svg` — Monocromático Grafite `#161a23`, para impressão em uma cor ou fundos brancos sem cor.
- `tabwallet-mark.svg` — Símbolo isolado: favicon, ícone do app (PWA), avatar. Mínimo 16px.

Área livre ao redor: metade da altura do símbolo. Assinatura horizontal com no mínimo 160px de largura; abaixo disso, use o símbolo. Nunca recolorir, distorcer, rotacionar, contornar ou reorganizar. Nas telas, prefira o componente `Logo`, que acompanha o tema.
